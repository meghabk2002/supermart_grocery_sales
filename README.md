# Supermart Grocery Sales — Profit Margin Analysis 🛒

## 📁 Project Structure
- `supermart_profit_analysis.ipynb` — Main analysis and ML notebook
- `Supermart Grocery Sales - Retail Analytics Dataset.csv` — Dataset
- `README.md` — This file

---

## 🧪 Tools and Libraries Used
- **Pandas & NumPy** for data manipulation
- **Matplotlib & Seaborn** for visualisations
- **Scikit-learn** for machine learning models
- **XGBoost** for gradient boosting classification
- **SHAP** for model explainability
- **Jupyter Notebook** for code execution and documentation

---

## 📊 Project Methodology
- Data loading, cleaning and preprocessing
- Exploratory Data Analysis (EDA) with visualisations
- Feature engineering and target variable creation
- Classification modelling — Logistic Regression, Random Forest, XGBoost
- SHAP explainability to interpret model predictions

---

## 📈 Model Results
| Model | Accuracy |
|---|---|
| Logistic Regression | 76.54% |
| Random Forest | 76.94% ✅ Best |
| XGBoost | 75.14% |

---

## 🔍 Key Insights
- **North region** outperforms all others with ~32% average profit margin
- **Health Drinks and Soft Drinks** are the top profit-generating sub-categories
- **Sales amount** is the strongest predictor of high profit orders (SHAP analysis)
- **Discounting** does not significantly impact profit margins across any level
- **Sales grew consistently** from 2015 to 2018 indicating a healthy growing business

---

## 🎯 Business Question
Can we predict whether a grocery order will fall in the top 25% of profit, and what factors drive profitability?
